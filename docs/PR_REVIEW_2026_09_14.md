## Validation and boundaries

- Actionlint 1.7.12 accepted the merged workflow YAML/expressions. Shellcheck was
  unavailable and disabled; this is not a claim of executing GHCR publishing,
  Sigstore signing or the GitHub-hosted release workflow locally.
- Starlette 1.6.0 / chardet 7.6.0 / FastMCP 2.14.7 were tested in a disposable
  Python 3.13 environment sharing existing dependencies: **67 passed** across
  MCP host, issue regressions, streaming/download parity and content ingestion.
  This experiment does not widen the shipping chardet constraint.
- A separate isolated FastMCP 3.4.7 environment reproduced the resource-manager
  incompatibility. No production dependency was replaced by either experiment.
- Review exposed a stale closed-schema count after Delivery Evidence: assert
  43 rather than 41 and explicitly require both new delivery tools. Preserve
  recursive closed-schema and board-scope validation for every tool.
- The import-boundary audit exposed undeclared delivery helpers and two older
  exploration imports. Declare only the two pure delivery helper contracts;
  route exploration through the public, storage-neutral application facade.
  Synchronize the paired manifest expectation. The private-import budget remains
  zero, with **1,217 public imports, zero private imports and zero violations**.
- Final follow-up: **49 Community tests passed** for architecture/contributor
  contracts, public-import boundary, exploration API and the contributor's CLI
  regression; **10 Core manifest/import-governance tests passed**. Scoped Ruff
  checks, Actionlint and offline lock validation also passed.
- The existing local candidate-wheel source is required to resolve the lock
  because Core 0.3.3 is not on PyPI. Use the already documented command:
  `uv lock --check --find-links ../okto_grafx/.grafx-tmp/language-wheel`.
  This review does not publish a Core package or replace that candidate wheel.
  Grafx's original PyPI source, artifact hashes and timezone dependency are
  preserved; no candidate Grafx wheel replaces the published 0.0.6 artifact.
